#To-Do List
A simple command-line To-Do list written in python for training OOP and CSV.
#Features
1.Add tasks
2.Remove tasks
3.Display tasks sorted by priority
4.Save tasks to a CSV file
5.Load tasks from a CSV file
6.Command-line menu
#Technologies
Python
Object-Oriented Programming
CSV
#Project Structure
ToDoList/main.py
ToDoList/README.md
ToDoList/tasks.csv
#How to Run
Run:
python main.py
#How It Works
Each tasks has: Subject, Priority
A lower priority number means a higher priority.
